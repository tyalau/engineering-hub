# @tyalau/eslint-config

The central source of truth for code quality standards across the `engineering-hub`.

## 📦 Available Configurations

| Config | Usage | Key Features |
| :--- | :--- | :--- |
| `@tyalau/eslint-config/base` | Pure TS/JS, Node.js | Strict TS, Import sorting, Turbo rules. |
| `@tyalau/eslint-config/react` | Vite, React Libraries | React 18+ (JSX Runtime), Hooks, Refresh. |
| `@tyalau/eslint-config/next` | Next.js Apps | Core Web Vitals, Next-specific patterns. |
